# Style

- Standard Catalan following IEC norms. Terse, clear and atmospheric, matching Metroid's tone;
  no jokes needed.
- English is the source. The EU Spanish text is a reference for meaning and length only; don't
  copy its terms when the glossary differs. Other translations are references for meaning, never
  copied verbatim.
- Sentence case for item and UI names ("Raig de càrrega"). Proper names and the Galactic
  Federation keep their capitals. Location banners are written in capitals, as in vanilla.
- "la Samus" in prose, with the personal article.
- Keep untranslated: Samus Aran, Ridley, Kraid, Mecha Ridley, Zebes, Chozo, Mother Brain and the
  area names (Brinstar, Norfair, Crateria, Tourian, Chozodia).
- Write real l·l (the font has a fixed middle dot).
- When a line overflows, reword instead of abbreviating.
- Keep every control code ({COLOR(n)}, {INDENT(n)}, buttons, \n) as in the Spanish original.
  GAPs are recomputed by `tools/gap.py fix`.
- Use only characters in charmap.txt; `”` (not `"`) for quotation marks.
